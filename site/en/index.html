Getting started with Unity MCP

This package connects the Unity Editor to Claude. You describe what you want. Claude can then look through your scene, add objects and read the errors in the Console.

If you only want to work on an avatar, you never type a command. You do not need to open a terminal.

What you need

  • Unity Editor 2022.3 or newer
  • Git, from git-scm.com. Unity uses it in step 1 to fetch the package. Without it the Package Manager stops with "No 'git' executable was found". The installer's defaults are fine. If you use VCC or ALCOM, the next section installs the package without Git
  • Claude Desktop, for the route with no commands. It ships for Windows and macOS. On Linux, take route B
  • The project open in the Unity Editor the whole time you use it

If you use VCC or ALCOM

If you manage your project with the VRChat Creator Companion (VCC) or with ALCOM, install the package from its VPM repository instead. That route needs no Git. VCC and ALCOM download a package as a zip, so neither of them runs Git the way Unity's Package Manager does.

The link below opens VCC or ALCOM and asks you to confirm that you want to add the repository. VCC 2.1.0 or newer is required.

Add the Unity MCP repository

If nothing happens when you press it, add the URL by hand. In VCC that is the Add Repository button on the Packages tab of the Settings page. In ALCOM it is the Add Repository button on the Repositories page under Resources.

The repository URL 
https://unity-mcp.shiranui-isuzu.dev/vpm.json

Once the repository is added, Unity MCP appears in your project's package list, and you install it from there.

If you installed the package this way, skip the first step of route A and of route B below and start from the second.

A. I only want to work on an avatar

There are five steps in all. There is not a single command in this route.

  1. Install the package in Unity

    In the Unity Editor open Window > Package Manager. Press the + button at the top left and choose Add package from git URL. Paste the URL below and press Add.

    The URL to paste 
    https://github.com/isuzu-shiranui/UnityMCP.git?path=jp.shiranui-isuzu.unity-mcp

    If you installed the package through VCC or ALCOM above, you have already done this. Go on to the next step.

  2. Check that it is running

    Open the Editor's Preferences window and choose Unity MCP in the list on the left. On Windows, Preferences is under the Edit menu. When the first row under Setup reads "✓ Listening on port", the Unity side is ready.

    The server starts by itself when the Editor opens a project. There is nothing to start by hand.

  3. Download the extension

    Open the Releases page on GitHub and download the file named isuzu-unity-cli.mcpb.

  4. Double-click it to install it into Claude Desktop

    Double-click the file you downloaded. Claude Desktop shows an install screen for the extension. You can leave the Unity project name field empty when only one Unity project is open.

    The bundle is self-signed. Claude Desktop writes a warning to its log about an unsigned extension when it installs. The extension works regardless. Dragging the file onto the window does the same thing, and so does choosing it under Settings > Extensions > Advanced settings > Install Extension. If double-clicking opens a window that closes again straight away, that is a known issue with the Microsoft Store build of Claude Desktop. Rename the file to .zip and extract it. Then pick the folder with Install Unpacked Extension on the same screen.

  5. Start talking to it

    Keep the project open in the Unity Editor and write what you want in Claude Desktop. Nothing works while the Unity Editor is closed.

B. I also write code

Install the command line tool isuzu-unity-cli and use it from Claude Code. The published binaries are native, so they need no Node.js and no .NET runtime.

  1. Install the package in Unity

    This is the same as the first step of route A. Open Window > Package Manager and paste this URL into Add package from git URL.

    https://github.com/isuzu-shiranui/UnityMCP.git?path=jp.shiranui-isuzu.unity-mcp

    If you installed the package through VCC or ALCOM above, you have already done this.

  2. Install the command line tool

    Run one line in a terminal.

    Windows (PowerShell) 
    irm https://raw.githubusercontent.com/isuzu-shiranui/UnityMCP/main/install.ps1 | iex
    macOS / Linux 
    curl -fsSL https://raw.githubusercontent.com/isuzu-shiranui/UnityMCP/main/install.sh | sh

    With the .NET SDK installed, dotnet tool install -g IsuzuUnityCli works too. You can also download a binary directly from Releases. The Install CLI button in Preferences > Unity MCP opens a terminal and runs this install script for you.

  3. Install the agent skill

    This installs the skill for Claude Code and Codex.

    isuzu-unity-cli setup

  4. Register the endpoint with Claude Code

    One line registers both the URL and the token. You never handle the token yourself.

    isuzu-unity-cli setup --mcp --agent claude-code

    --agent accepts claude-code, claude-desktop, codex, cursor, gemini and vscode. The Unity Editor has to be running when you run that command. Every command is in the CLI reference. The per-client configuration is in Connecting MCP clients.

What you can do once it is connected

  • Walk the scene hierarchy and find the GameObject you mean.
  • Create GameObjects, add components, and change position, rotation and scale.
  • Read and write the serialized properties you see in the Inspector.
  • Read the errors and warnings in the Console, or read Editor.log directly.
  • Take screenshots of the Game view and the Scene view.
  • Read the current values on a material and change them.
  • Start and stop Play Mode.

The Editor publishes at most 88 tools. The Timeline and Recorder tools appear only in projects that have those packages installed. A project with neither publishes 75 tools. The full list is in the tool reference.

When something goes wrong

The Unity Editor is not open

Every tool acts on a running Unity Editor, so nothing answers while the Editor is closed. Open the project again and check that Status reads Listening in Preferences > Unity MCP.

Several projects are open at once

With more than one Unity Editor running, there is no way to tell which project you mean. Type the name shown in the Unity Editor title bar into the project name field, which is in the extension's settings in Claude Desktop. The Product Name from Player Settings works too. If both names still match several Editors, closing the others is the sure way.

Read the per-client setup

The tools do not show up

When adding or removing a package changes which tools exist, no notification is sent to the client. Reconnect Claude Desktop or Claude Code.
